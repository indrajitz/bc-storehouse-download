Install

One Setup for everyone: no admin rights, about a minute. Only the library you point it at is different.

Coming from 1.25? Update everyone on a shared library together.

Versions before 1.52 throw away what newer versions record when they save an asset, including where each tag came from and its undo history. Once one person moves to 2.0, nobody else should keep editing that library with 1.25.

In the studio

You have the shared library on N:

  1. Run the Setup and press Install. If the old version is open, Setup offers to close it.
  2. It replaces 1.25 in place, so your Start menu and desktop shortcuts open 2.0.
  3. Open it. Your library, tags, kits and notes are where you left them. If it asks for a library, choose the studio library on N:.
  4. Settings: install the Cinema 4D and Houdini helpers again. Sends work differently in 2.0, and the old helpers don't report back.

Outside the studio

You'll keep your own library.

  1. Run the Setup and press Install. It adds BC Storehouse to the Start menu and opens it.
  2. Choose a library folder. Use an empty folder to start, or one you already have. Nothing in it is moved or renamed until you import.
  3. Say yes to the picture model (373 MB, asked once). It comes from Hugging Face and is checked byte for byte before use. Without it, tagging works from names only; you can get it later in Settings › Import & tagging.
  4. Settings: install the Cinema 4D and Houdini helpers to send assets into your scenes.

"Windows protected your PC"? The Setup isn't code-signed yet. Choose More info, then Run anyway.

Updating later: run the newer Setup over it. Removing it: Windows Settings › Apps › BC Storehouse; your library and its index are left alone.

Many machines at once: BC-Storehouse-Setup-2.0.0.exe /VERYSILENT installs for the signed-in user with no questions. Rather not install? The portable zip (110 MB) runs from any folder.

What's new since 1.25

Forty-two releases since 25 September, in one download. The changelog has every one of them.

A new window

  • Rebuilt in Qt to the studio's design. It opens in about a second, and a second click brings the open window forward.
  • Quick look: Space shows a big picture, the arrow keys go through the grid, C or H sends.
  • Ctrl K goes to anything: a category, a kit, a page or an action.
  • Opens where you left off. Grid or list, compact tiles, and hover buttons to pin and send.

Importing

  • Drop a zip, even one with zips inside. Storehouse works out what each thing is and shows the plan before anything is copied.
  • Spots names already taken, files already in the library, and materials missing a map.
  • An Inbox for imports someone should look at first, or import straight into a kit.
  • Reads vendor files, such as Megascans' own tags.

Tagging you can trust

  • One tag box everywhere. Type any word; a new one asks once which group it belongs to.
  • The picture tagger runs on the graphics card, about four times faster, and only suggests what it's sure of.
  • Hover a tag to see where it came from: the name, the vendor, the picture or a person.
  • Ctrl Z undoes tag, name and description changes. Proposals let a reviewer approve changes first.

Finding things

  • Find similar, or drop a picture on the search box to find what looks like it.
  • Search for a look ("worn wood"), filter by size (1K–8K) and by the application it's made for.
  • Smart collections (Untagged, Needs review), saved filters, a Most used sort, and Compare for two to four assets.

Looking closer

  • HDRI viewer: exposure, a histogram in stops, a chrome ball, and correct ACEScg.
  • Models: size and units, UVs (single tile or UDIM), materials and missing textures, and LODs.
  • Preview renders: materials on a sphere, cloth and cube, models as a clay turntable (Houdini + Redshift).
  • Setups and courses play in the window, with notes stamped at the timecode and progress per course.

Into the scene

  • Every send is queued and answered: Storehouse says what Cinema 4D or Houdini built, or why it couldn't.
  • An HDRI becomes a dome light at the exposure you were viewing; models arrive at the scene's scale.
  • Install HDAs and plug-ins with update, roll back and undo. Works with checks what a setup needs.
  • Export any material as USD.

Projects and kits

  • Projects: see every file a scene uses, then package it for travel, relinked and checked.
  • Take a kit offline and merge your changes back later.
  • Versions, notes, and source and licence details kept with each asset.

Nothing lost

  • Says when the library is offline and waits for it, instead of failing part-way.
  • Sending twice no longer loses the first send, and a failed export keeps the old archive.
  • Daily index backups that can be restored, and a trash with Restore.
  • The library on disk is still the truth: every tag and note lives in the asset's own folder.

What it needs

Everything else is optional; the app says plainly what is and isn't on the machine.

To run

Windows 10 or 11, 64-bit. About 215 MB on disk, plus 373 MB for the picture model.

To send

Cinema 4D and/or Houdini, with the helpers installed from Settings. Tested with Cinema 4D 2026 and Houdini 21 and 22.

To render previews

Houdini with Redshift for materials and models. HDRI previews need nothing extra.
